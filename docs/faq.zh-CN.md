## Krux 是硬件钱包吗？
Krux 更准确地说是一个离线签名设备固件。它可以运行在专用硬件上，完成创建助记词、导入助记词、离线签名、二维码传输和助记词备份等工作。

Krux 早期更偏向“只在用的时候加载密钥”的签名器，但现在也支持把助记词加密后存到设备内部存储或 SD 卡中，体验上更接近传统硬件钱包。

Krux 不内置安全芯片，已保存数据的安全性依赖加密和你的备份习惯。无论你用的是设备内存还是 SD 卡，都不要把它当成唯一备份。

## 为什么助记词编号从 0 开始？
BIP39 词表本身就是 0 到 2047 的序号。Amigo 上的助记词编号、钢板打孔数字和 TinySeed 都统一按这个口径显示和输入，避免把 1-2048 和 0-2047 混在一起。

如果你在看位权，Amigo 的大屏会把 `1 / 2 / 4 / ... / 1024` 从左到右排出来。扫描还原、手动输入和打印都会沿用同一套映射，不需要你自己换算。

## Amigo 版为什么不做智能卡？
这份 Amigo 固件的商业化方向是把签名、备份、导入导出、打印和触摸交互做好，不再保留树莓派那条直连智能卡的路线。

原因很简单：

- Amigo 不是树莓派 Linux 环境，不能直接复用 `pyscard` / `pcscd` / `ACR39U` 这条链路
- 智能卡功能会增加驱动复杂度、售后复杂度和用户误用风险
- Amigo 当前更适合把时间花在屏幕、触摸、扫码、打印和助记词工具上

如果你的核心需求就是智能卡读卡器，这份 Amigo 固件不是合适的目标。

## 现在还能连接哪些设备？
Amigo 适合连接这些外部设备：

- 通过摄像头扫码的二维码钱包
- 支持 TTL 串口的热敏打印机
- microSD 卡

Amigo 不适合直接连接 USB ACR39U 这类桌面智能卡读卡器，也不把它当主线支持目标。

## 为什么固件看起来只有几百 KB？
`firmware.bin` 本身就是设备固件镜像，体积本来就不大。真正写到板子里的，是它和启动打包文件一起组成的刷机包。

如果你是在 `firmware/MaixPy/projects/maixpy_amigo/build/` 里看到 `maixpy.bin`，那是更底层的应用镜像，体积通常更小也很正常。它和 `build/firmware.bin`、`build/kboot.kfpkg` 不是同一层级的交付物。

如果你看到的是几十 MB 或上百 MB 的压缩包，那通常是：

- 包含多个设备的 release 压缩包
- 包含刷机工具、说明、校验文件的安装器
- 不是单独的 Amigo 固件本体

## Amigo 有两个 USB 口吗？
是的，Amigo 在连接和刷机时通常会出现两个串口表现，这是正常现象。

最稳妥的经验是：

1. 优先使用 **底部** 的 USB-C 口
2. 如果电脑识别出两个串口，先按文档流程试自动刷写
3. 如果自动识别失败，再手动指定串口

## 触摸屏不工作怎么办？
先确认你刷的是 Amigo 对应固件。Amigo 本身是触摸屏设备，屏幕能亮但完全不响应触摸时，优先按下面顺序排查。

1. 先重启一次，开机时手指不要压在屏幕上。Krux 支持“按住屏幕开机临时禁用触摸”，如果开机时手碰到屏幕，可能会进入只能用按键操作的状态。
2. 如果重启后仍然完全不能触摸，打开 Amigo 外壳，检查主板中间偏左的触摸 IRQ 小开关。Krux v24.03.0 之后要求这个小开关在上方位置，否则触摸不会工作。
3. 小开关拨好后重新上电，再进入 `工具 -> 触摸测试` 或 `固件自检 -> 触摸测试` 检查。

如果屏幕能亮、但触摸方向不对或者颜色不正常，先去 `设置 -> 硬件 -> 显示` 里调整：

- `Flipped X Coordinates`
- `Inverted Colors`
- `BGR Colors`
- `LCD Type`

如果触摸完全不响应，也可以试着用按键方式进入自检和设置页，逐项排查。

## 能不能接 Brother 7470DF 这种 USB 打印机？
不能直接把它当成电脑那种 USB 打印机来用。

Krux 的打印功能面向的是 **本地连接的 TTL 串口热敏打印机**，不是 USB 打印机驱动方案。也就是说：

- 支持的是 QR、助记词、地址等内容的热敏打印
- 不支持直接驱动 Brother 这类 USB 办公打印机

如果你要的是“打印二维码/备份卡片”，请选 Krux 支持的热敏打印方案。

## 安卓 App 还要继续做吗？
这份 Amigo 固件不做 Android 方向。Android 版是另一个独立项目，主要用于学习和测试，不适合作为正式资产管理设备。

如果你要的是正式使用和商业交付，请以 Amigo 固件为准。
